# 总体研究计划

## 目标

研究机械臂指令与实际执行的偏差：先验证误差可测、可重复、可预测和可补偿，再判断世界模型相对普通反馈与历史策略的额外价值。不以人为压低SAC成功率作为目标。

## 当前范围

用户指定Claude先执行 [独立环境配置](tasks/task0/PROCEDURE.md)。本轮授权最小源码准备、必要容器依赖适配、构建、启动和基础反馈检查；均尚未执行。完成后进入 [正常执行测量](tasks/task1/TASK.md)。控制误差注入、SAC和世界模型不在本轮范围。

## 建议顺序

|顺序|要回答的问题|继续推进的依据|
|---|---|---|
|正常跟踪测量|现有命令与真实关节响应是否有偏差，偏差来自哪里？|时间对齐正确，误差可测且可重复，IK与执行误差分开|
|一种受控执行误差|能否产生有结构、可重复的执行滞后？|关闭扰动恢复正常行为，开启后偏差可控，无未解释的不稳定|
|已知模型补偿诊断|准确预测信息是否能改善跟踪？|有合适对照和重复实验，确认改善来自补偿机制|
|SAC与世界模型对照|世界模型是否提供历史SAC之外的收益？|明确训练分布、信息、重训方式及预算，任务指标改善|

后续问题尚未实施，不预设任何阶段已经通过。若证据不支持继续，更新假设与方案。
