### 四、精读要求

逐篇回答：
1. 论文解决的具体问题是什么？其观测、动作、平台和任务条件是什么？
2. 核心机制是什么？指出关键公式、图、章节；有必要时只读官方源码定位实现。
3. 它如何处理观测差异或底座/机械臂耦合？如果没有直接处理，明确写出。
4. 哪项实验或消融支持这一机制，哪些仅支持整体效果？报告关键对照和限制，不能把成功率提升直接当成机制证明。
5. 对我们能借鉴什么，需要哪些额外观测、标签、模型、训练数据或动作权限？哪些条件当前不具备？
6. 原方法没有解决什么？这一空白是否与我们的两个科学问题直接相关？

分清“已读全文”“仅读摘要”“核查了部分源码”。读不到全文就明确降级证据，不冒充精读；不要照搬跨任务成功率排名。

### 五、形成具体研究候选

基于精读提出2～3个候选方案，最后优先推荐1个。每个方案必须给出：
