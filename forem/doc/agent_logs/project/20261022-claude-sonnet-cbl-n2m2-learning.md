## 0. 结论摘要

1. 【事实/复算】同一份 CBL 自写 SAC 配方（task5.5，我们 v4 下层的 SAC 骨架直接来自它）在 sim 里：D15 内部成功 25k 步已约 0.4，然后在约 0.4–0.5 平台上停留到约 3M 步，3.5M 步之后才升到约 0.6，5M 终评 0.63（32/33/30，/50）。所以“1M 步还很低”本身不反常。
2. 【事实】RLlib 路线（N²M²上游 PR2，及 CBL 原版 Husky）的样本效率明显更高：约 15 万步 0.44–0.52，约 30 万步 0.66–0.78，之后平台 0.76–0.88。N²M² 论文本身没有“成功率–步数”曲线，只有终评。
3. 【复算＋推断】按“无失败的概率÷平均长度”估计的每步首次失败风险：CBL 约 0.2–0.4%/步；v4 同步变体约 4–6%/步，约为 CBL 的 15–25 倍；v4 不同步变体约 0.1–0.17%/步，和 CBL 同量级，但 70–76% 的段超时。即两个变体的问题不同：同步是“安全/可行性”问题，不同步是“推进”问题。该估计是粗算，假设风险恒定。
4. 【事实】CBL/N²M² 的 IK 求解里，自碰撞默认不计失败（`selfcollision_as_failure=false`，进入自碰撞只保持上一组臂关节）。v4 里自碰撞是硬失败，在同步变体约占段的 40%、占失败的一半以上。
5. 【事实】N²M² 训练目标经过可解性筛选（拒绝 0.4 m 膨胀地图里无路径的目标），而 v4 子目标是从规则候选里不筛可行性地均匀抽取。

## 4. 问题3：可能让我们学得慢的结构性差异（每条标证据）

### 4.1 同步变体每步失败风险比 CBL 高一个数量级【复算＋推断，强度：中】

- 计算：每步首次失败风险 h≈−ln(p)/L，p＝“整个回合/段内无失败”的概率，L＝平均长度（步）。这是粗估：假设风险恒定、不分回合内位置；CBL 的 p 用 D15 的“零 IK 失败且零底盘碰撞”回合比例，v4 的 p＝1−failed_rate。

| 对象 | p | L（步） | h（每步） |
|---|---|---|---|
| CBL D15 25k | 0.37 | 246 | 0.41% |
| CBL D15 1M | 0.43 | 295 | 0.28% |
| CBL D15 5M | 0.59 | 235 | 0.22% |
| v4 同步 250k / 500k / 750k / 1M | 0.22 / 0.22 / 0.30 / 0.24 | 26 / 28 / 30 / 25 | 5.7% / 5.5% / 4.0% / 5.8% |
| v4 不同步 250k / 500k / 750k / 1M | 0.86 / 0.88 / 0.85 / 0.82 | 128 / 129 / 126 / 122 | 0.12% / 0.10% / 0.13% / 0.17% |

- 解读（推断）：同步变体的风险是 CBL 的约 15–25 倍，且 250k–1M 没有下降趋势；不同步变体的风险与 CBL 同量级，它的问题是推进（70–76% 超时）。
- 证据缺口：没有区分“策略能力不足”与“被要求去不可行的位置”。task7.18.5 正在用 G7 可行性判定做这件事，结果出来后才能下结论。

### 4.2 自碰撞是硬失败，而 CBL 里不计入【事实＋推断，强度：事实强／影响中】

- 事实：`forem/src/modulation_rl/scripts/modulation/envs/robotenv.py:297-298`：`if not self.selfcollision_as_failure and robot_obs.in_selfcollision: robot_obs.ik_fail = False`，合同 `forem/config/task3/task_contract.yaml:47` 为 false；之后只有末端偏差超过 0.1 m 或姿态距离 0.05 才再记失败（`:299-300`）。N²M² 论文 Sec. III-B 也说 IK 求解被限制在满足关节限位与自碰撞的解里（论文原文“restricted to solutions that adhere to joint limit and self-collision constraints”）。
- 事实：v4 同步变体的自碰撞占每段 40%（1M），是最大单项；不同步 8%。训练中失败动作步里自碰撞占 42%（26277/61548，1.06M 步，`learning.jsonl` 的 `step_failures`）。
- 推断：把“CBL 不计的那一类”当硬失败，会让 v4 的失败率相对 CBL 偏高，并且几何是保守近似（task7.18.2 已记录“上臂–顶板整对放行”等限制），可能包含误报。误报比例没有测过，不能量化。

### 4.3 子目标是均匀抽取，未做可解性筛选【推断，强度：中弱，待 task7.18.5】

- 事实：N²M² Sec. III-F “reject any goal for which no valid path can be found in a map with an inflation radius of 0.4 m”，并称相比课程学习与对抗生成，“直接随机化并最大化多样性”更简单也更有效（论文原话，未见对照实验）。
- 事实：v4 子目标取规则候选的均匀随机（task7.13 L.4，D5/D6，SRC-0401），12 个方向中包含背向末端路线的方向；同步变体的末端进度不受候选约束。
- 推断：同步变体里底盘走向与末端路线不一致的候选，会把机械臂拉出可达范围，造成 IK 失败与自碰撞。这条解释和 §4.1 的高风险相容，但没有直接证据；task7.18.5 的“G7 可行比例/可行子集上的到达率”会给出证据。

### 4.4 训练长度与 lr 日程【推断，强度：中】

- 事实：同一 SAC 配方在 CBL 任务上 3M 步前基本平台，3.5M 步后才上升（§2.2）。v4 的网络、lr 日程、α 规则、batch、replay 都沿用该配方（task7.18 RESULTS L.8、SRC-0406），1.06M 步时 lr 约 3.8e-5。
- 推断：把 v4 在 1M 步的低水平直接判为失败偏早；但 CBL 的平台期里回合成功率已经是 0.4–0.5，而 v4 同步的段到达率 0.17（单位不同，只示意量级）。所以“慢”只能解释一部分差距，不能解释 §4.1 的数量级差异。

### 4.5 不同步变体缺少推进压力【推断，强度：弱–中】

- 事实：v4 不同步奖励为 B＋G，没有时间项（SRC-0913），段超时 70–76%，平均段时长约 12–13 s（与 T_seg 的量级相当，未逐段核对）；失败率只有 12–18%。N²M² 用 −(v_max−n)² 项推动提速，CBL 同步沿用。
- 事实：此前（v3）带固定时间惩罚的不同步变体出现了“主动失败”漏洞（task7.18.4 的 SRC-0911/0912/0913 的记录），所以简单加回时间项并不安全。
- 推断：没有时间或到达压力时，策略可以“待着”避免失败；进度项 w_s·Δs、w_d·Δρ 每步量级 ≤0.03，相对 B 里的惩罚较小。未经实验验证。

### 4.6 更新比例与温度（对比 RLlib）【事实＋待证，强度：弱】

- 事实：RLlib 每步约 0.1 次更新、初值 α＝1.0、α lr 1e-4，30 万步即到 0.66–0.78；自写 SAC 每步 1 次更新、α lr 1e-6、α 冻结在 0.05，5M 才到 0.6（task6.1 的筛选里单项改动都不显著，F2 只换 α 规则更差，F1/F6 每 10 步更新约 +0.04–0.06 但区间含 0）。
- 推断：两种实现的差距来源未明（PLAN 已列为“尚未弄清”）。v4 沿用自写 SAC，所以可能继承这个“慢”。

## 6. 我们可能差在哪（3–6条；证据强度；不是实施建议）

1. 同步变体的每步失败风险约为 CBL 的 15–25 倍（§4.1；复算，证据中）。可选方向：先量化其中“候选本身不可行”的份额（task7.18.5 正在做），再决定是否对训练子目标做可行性筛选或分档。
2. 自碰撞作为硬失败且几何保守（§4.2；事实强，影响大小未量化）。可选方向：测保守几何的误报率；或让训练的自碰撞处理更接近 CBL（保持上一组关节，不计失败）。后者改变科学条件，需用户决定。
3. 子目标均匀抽取含大量与末端路线不一致或不可达的方向（§4.3；推断，证据中弱）。N²M² 对目标做可解性筛选。
4. 1M 步仍处于同配方的平台期（§4.4；证据中）。可选方向：不要仅凭 1M 判断，参考 CBL 在 3.5M 之后才上升；看 v4 在 lr 变小阶段的变化。
5. 不同步变体的问题是推进而不是安全（§4.1、§4.5；证据弱–中）。可选方向：reward 中的推进信号强度、帧跳课程；加回时间项曾引出“主动失败”漏洞，需谨慎。
6. 自写 SAC 本身样本效率低于 RLlib（§2.1、§4.6；事实：同任务同步数差距明显；原因未明）。v4 继承此配方，所以部分“慢”可能是这个实现的特性，而不是我们的任务设计。

## 7. 限制与未做的事

- 所有 CBL/N²M² 数字都是单种子或三种子、各 50 回合，没有显著性检验；不同曲线用了不同的评估口径（RLlib Tune 评估、D15、终评），场景也不同（半椭圆柱 vs 全矩形）。
- 每步风险估计是粗算，假设风险恒定；CBL 的“p”包含到达路线终点的回合，v4 的 p 包含超时的段（超时并非失败，但也并不代表安全）。
- v4 的数据只取到 1M 步检查点；训练仍在进行，本报告不对最终结果作判断。
- 没有重新打开 archive，没有运行任何评估；N²M² 论文文本来自 `/tmp/research-028-literature/n2m2.pdf` 的 pdftotext 提取（临时路径，不是长期证据；登记在 SRC-0935 里写了 arXiv 编号与节/表位置）。
- CBL 的自碰撞在日志中没有单独字段，所以无法算出 CBL 里“若计入自碰撞会增加多少失败”。
- 未审计 CBL 编码器、IK 求解器（BioIK 与我们 UR5 解析/DLS）的差别对失败率的贡献。
