## 1. 这篇论文在解决什么问题

论文：Xuan Yao等，*SC²-WM: A Self-Correcting World Model with Closed-Loop Feedback for Vision-and-Language Navigation in Continuous Environments*。本次以用户上传PDF为准，书目信息仅按文档自述，不重新核验发表状态。[原文与范围：SRC-0318](../../SOURCES.md#src-0318)

视觉语言导航：根据语言指令和视觉观测，在环境中找到目标。连续环境要求智能体逐步移动；部分可观测意味着当前画面不足以完整确定环境与导航进展，需要历史信息。本文任务使用RGB-D和语言指令，根据候选航路点选择动作，由底层连续控制执行；不能仅凭“连续环境”推断策略输出必是连续数值。[SRC-0318](../../SOURCES.md#src-0318)

作者认为，已有方法缺少执行前对动作后果的内部校验，内部理解可能逐渐偏移。此处“开环”是作者对特定内部预测—修正机制缺失的描述，不表示已有策略完全不接收环境观测，也不表示所有开环方法必然累积错误。漂移应理解为内部表示偏移，而非“状态流失”。[SRC-0318](../../SOURCES.md#src-0318)

## 2. 一步决策过程：先想象，再决定

1. 编码当前观测，结合历史视觉记忆进行校准。
2. 结合上一步修正后的状态、上一步实际执行动作和当前观测/指令，形成当前潜在状态s_t。形式上的策略依赖全部观测与动作历史；实现可由递归状态保存，不必每次重输完整历史。
3. 前瞻策略π̃提出候选动作ã_t，尚不执行。
4. 世界模型预测执行候选动作后的状态：s̃_(t+1)=f_p(s_t,ã_t)。
5. 计算预计变化Δ_t=s̃_(t+1)−s_t。
6. 网络ψ结合当前状态与预计变化，得到修正表示s_t^(Δ)=ψ(s_t,Δ_t)。
7. 最终策略π根据修正表示输出实际动作a_t；执行并获得新观测，进入下一步。

以上为图2、公式1–10和算法1的阅读摘要；f_p使用Transformer，本文构造反馈时采用预测分布的均值，避免额外采样噪声。[SRC-0318](../../SOURCES.md#src-0318)

**今天最关键的理解：Δ不是预测错误，而是动作预计带来的变化。** 它比较当前状态与预测未来状态，不是预测未来与实际未来。动作带来变化很正常，作者明确说Δ不是需要最小化的训练目标。网络利用这种变化辅助当前决策；不能仅由Δ证明当前状态错了或漂移已被检测到。[原文§3.1、式9–10；解释与推导边界：SRC-0318](../../SOURCES.md#src-0318)

直观类比（教学例子，不是论文实验）：准备左转时先想象转后面向哪里，再利用预计后果决定最终动作。“纠正”在这里应先理解为预测后果辅助表示调整，不能直接等同于消除一个可观测误差。

## 3. VCM：用历史帮助读懂当前画面

VCM保存近期视觉记忆m_i，并结合相对空间、时间信息构建检索键k_i。用当前特征v_t检索相关历史，注意力汇总出上下文c_t，同时通过时间衰减降低较远历史的权重。[§3.1、式8：SRC-0318](../../SOURCES.md#src-0318)

随后融合：v̂_t=α_t⊙v_t+(1−α_t)⊙c_t。其中α_t为逐特征的门控权重。今天补查本地参考实现GateFusion：α_t=sigmoid(W[v_t;c_t]+b)。训练学习W和b，运行时按输入计算α，不是每一步单独训练一组α。[实现证据：SRC-0319](../../SOURCES.md#src-0319)

理解：当前画面遮挡严重时，历史信息可能有帮助；但代码没有写死“遮挡越多、历史权重越大”，也不能证明网络一定学会该规律。VCM校准当前视觉特征，再据此推断当前状态，不是回头修改所有历史状态。[原文与示例限制：SRC-0318](../../SOURCES.md#src-0318)

## 4. “预训练”训练什么

这里“预训练”可以理解为测试前的正常训练；名称用于与测试时适应区分，不表示额外先训练一个大语言模型。整个SC²-WM联合学习导航行为与预测动态，而非只训练π或只训练世界模型。[§3.2：SRC-0318](../../SOURCES.md#src-0318)

|损失|监督或约束|直观含义|
|---|---|---|
|L_ac|修正前及修正后的动作预测，都使用专家动作监督|两种状态表示都应支持正确行动|
|L_wm|同一时刻的先验预测分布p与观测后验分布q进行KL对齐|没看新画面时的预测，接近看到画面后的状态推断|
|L_rec|d(s̃_(t+1))与下一步观测编码特征v_(t+1)的平方误差|预测下一步会看到的视觉特征|

总损失L=L_ac+L_wm+L_rec。后验不是直接的物理真值标签；先验—后验对齐与“未来状态减当前状态”的Δ是两件不同的事。视觉重建发生在特征空间，不是逐像素重画图像。[式11–13：SRC-0318](../../SOURCES.md#src-0318)

**纠正今日早先讲解：** 最初只讲了最终策略的动作损失，并说“不监督前瞻策略”，不完整。式11对修正前、修正后的动作预测均提供专家监督；不能把单项损失的直接监督对象与整条计算链所有可训练参数混为一谈。精确梯度及冻结边界未作完整代码审计。[SRC-0318](../../SOURCES.md#src-0318)

补充概念（教学解释，非本文新实验结论）：模仿学习依据专家示范学习行为，强化学习依据奖励学习长期回报；深度学习指用多层神经网络学习，可以与前两者组合。区别不是“有大量数据/没有数据”。本文式11使用专家动作的模仿学习监督，不据此推断专家一定是另一个训练网络。专家具体构造留待实验设置核查。[概念解释性质与证据边界：SRC-0318](../../SOURCES.md#src-0318)

## 5. 两层修正：改状态，还是改模型

|层次|什么时候做|改什么|
|---|---|---|
|状态层面|每步，实际动作执行前|当前潜在表示s_t→s_t^(Δ)，并据此生成最终动作|
|模型层面|测试期间满足条件时|世界模型参数Θ；正文明确不包含策略参数|

触发条件在完成状态细化、获得两个动作分布后计算；这不意味着本文已完全说明新观测到来、损失形成与参数更新在实际程序中的所有时序。[§3.3、算法2：SRC-0318](../../SOURCES.md#src-0318)

正文使用两个条件：①修正前后动作分布的KL差异κ较大，超过近期κ缓冲区的指定百分位；②最终动作分布的熵低于阈值，即策略较确定。此前“仅固定KL阈值”的解释是简化，不能代替正文规则；算法2又采用简写，完整实现本轮未核对。[SRC-0318](../../SOURCES.md#src-0318)

**核心保留疑问：为什么满足这两点，就要更新世界模型？**

作者把显著决策变化看作前瞻引导影响很大的信号，并用低熵过滤不确定情况。但这并不直接证明模型预测差：准确预测成功改变坏决策，也可能满足条件；自信也不保证正确。因此，这是作者提出的条件适应规则，不是已证实的预测错误检测器。其合理性与收益需要对照/消融证据，今天未读相关结果，不能写成“已证实有用”。[原文动机与逻辑分析分别登记：SRC-0318](../../SOURCES.md#src-0318)
