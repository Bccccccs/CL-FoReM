# task7.20 — 上层决策级批量环境与G1规则选点

状态：**done（2026-10-21 Claude复核r5通过并修正可行分支并列取间隙，见[RESULTS](RESULTS.md)末节）。原：draft（2026-10-21建立；实施已授权，[SRC-0439](../../../SOURCES.md#src-0439)；依赖task7.15、7.17复核done后派发）**。父任务：[task7](../TASK.md)。用户要求起草见[SRC-0438](../../../SOURCES.md#src-0438)。

## 目标

把task7.15候选生成器、task7.17回合环境、task7.14批量推演（`core.rollout`）与冻结下层策略组装成**一次`step`执行一个完整决策**的批量环境（半马尔可夫），供上层训练（task7.22）与各组评估使用；同时实现不学习的对照组G1（规则选点）。本任务不实现上层网络，不训练。

- 决策流程：父[TASK](../TASK.md) §2.7第1、3、7步；[task7.13 RESULTS](../task7.13/RESULTS.md) L.0（执行与推演）、D20（f_k v1、地图uint8量化与“量化→解码”同一路径）。

- G1：父TASK §4第1组；“可行”按冻结下层推演判定（推演到达且无预测失败），没有可行候选时按[SRC-0392](../../../SOURCES.md#src-0392)⑨的分层排序在全部候选中选。

## 范围

- 包含：
  1. `DecisionEnv`：`reset(seeds, map_ids)`→决策观测字典与候选集（c_k、掩码、f_k v1，K_max＝13补齐）；`step(k*)`→冻结下层以c*为子目标闭环执行（确定性动作）→下一观测、下一候选集、上层奖励及分量、Δt、terminated、truncated、info（r_t全部字段、触发原因、G1遮挡计数；被选候选的推演结论与实际结果，用于汇总“推演判可行但实际失败”“推演判不可行但实际到达”两类比例，只诊断不作门槛，[SRC-0520](../../../SOURCES.md#src-0520)）。
  2. 冻结下层策略接口：可调用对象（观测→确定性动作），可从task7.18检查点加载；同一对象同时用于推演与执行；加载时校验检查点、观测归一化与动作换算版本，并把版本写入info与导出记录。
  3. 每个环境独立自动重置；终止或截断时先保存最终观测与下一候选集。
  4. G1选择器（纯函数，读候选集与f_k）。
  5. 经验池所需的逐决策环境侧字段导出（task7.4 §12），不实现经验池本身（task7.22）。
- 不包含：上层网络、经验池与训练（task7.21、7.22）、f_p、G7执行器（task7.19）、测试期适应、ManiSkill。
