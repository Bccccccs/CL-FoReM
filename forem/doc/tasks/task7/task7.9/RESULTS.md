## (A) 规则版候选生成器规格

### A.1 职责、输入输出与信息边界

- 职责：每次决策开始时生成至多K_max＝13个候选前瞻点（12个扇区候选＋1个原地候选），供路径评估（task7.5 B.9）与离散SAC（task7.10）使用。
- 输入（**已定**，task7.5 B.8）：本次决策起点的局部栅格G（128×128×2，0.05 m/格，以机器人为中心、朝向对齐，task7.7）；本体状态（关节q、底盘世界位姿T_W,B_t）；任务给定的末端路线P(s)与当前进度s_cur（同步变体s_cur＝v_ee·τ）；变体标志v。
- 输出（**已定**，task7.4 §10第4行）：c_k＝(Δx, Δy, Δθ)，在B_t中表达；不同步变体另含s_k；有效掩码（只标补齐到K_max的空位）。决策开始时c*一次性换算成世界系目标、本次决策内固定（task7.4 §9锚定）。
- 信息边界（**已定**，I1，[SRC-0362](../../../SOURCES.md#src-0362)）：只读G、本体状态、末端路线与变体；不读真值地图或任何WorldTruth对象。末端路线由真值地图在回合开始规划，属任务给定输入（[SRC-0336](../../../SOURCES.md#src-0336)），不在本生成器里重新规划。
- 纯函数：不改变环境状态、随机数流与路线进度；不使用随机数；同一输入两次调用结果逐位相同。

### A.2 扇区候选（规则1–3）

1. **扇区**（**已定**12个30°扇区；中心方向为**建议**R6）：扇区j＝0…11的中心方向θ_j＝j·30°，在B_t中从正前方（x轴）起按逆时针（朝y轴）递增；与SC²-WM扇区以`direction_idx·30°`为中心的划分一致（[SRC-0395](../../../SOURCES.md#src-0395)）。
2. **候选位置**（**已定**固定距离、取小；数值**建议**R1）：扇区j的候选点位于B_t中(d·cosθ_j, d·sinθ_j)，d为固定距离，建议1.0 m（父TASK §2.8的示例值）。约束（推导，[SRC-0397](../../../SOURCES.md#src-0397)）：走廊须落在局部栅格内，d＋0.6 ≤ 3.2 m，即d ≤ 2.6 m。
3. **直线走廊检查**（**已定**“整车宽沿直线通过、该距离加0.6 m余量内有障碍则放弃”；几何细化为**建议**R2）：
   - 走廊＝B_t中以原点为起点、沿θ_j方向、长d＋0.6 m、宽0.67 m（车宽，[SRC-0330](../../../SOURCES.md#src-0330)）的矩形；0.6 m余量与原地转向外接圆半径≈0.60 m一致（同来源推导）。
   - 障碍判定与LocalCollision的底盘判定使用同一谓词和同一栅格覆盖函数：走廊覆盖的格中存在“已观测且最高高度>0”的格即放弃该扇区（task7.5 B.5）。
   - 未知格按空闲（B6已定，[SRC-0381](../../../SOURCES.md#src-0381)）：走廊经过未知区域不放弃；未知格的风险由路径评估的两项风险特征表达（task7.5 B.9）。
   - 这是生成阶段的粗筛：原地转向扫过的圆、曲线绕行、机械臂与障碍等都不在这里检查，留给路径评估。因此通过粗筛的候选仍可能路径不可行；直线被挡但曲线可达的方向会被放弃（限制，见A.7）。
4. **朝向**（**已定**规则3）：Δθ＝θ_j（朝运动方向）。

### A.3 末端进度s_k（规则4；只用于不同步变体）

- **已定**：对每个扇区候选的底盘位姿，沿末端路线找“机械臂可达且IK有解的最远进度”；同步变体的扇区候选不含s。
- 可达判据（**建议**，[SRC-0396](../../../SOURCES.md#src-0396)）：以IK为准。父TASK所写“约0.8 m”来自CBL/N²M²的`arm_range`，它在原代码中只是末端路线规划时底盘路径的膨胀半径，不是IK可达判据；本规格不把0.8 m当硬阈值。
- 计算（**建议**R3、R4）：
  1. 路线按弧长等间距Δs_r采样（建议0.05 m，与栅格分辨率一致），只看s_i ≥ s_cur的样本。
  2. 粗筛：UR5基座到该样本IK目标（tool0，按task7.5 B.4由TCP换算）的距离超过R_pre的样本直接判不可达。R_pre由展开URDF的连杆长度上界计算，只能放宽、不能误删，实现时用随机关节FK采样验证（[SRC-0397](../../../SOURCES.md#src-0397)）。
  3. 精判：对粗筛通过的样本调用task7.5 B.4的同一IK模块（UR5解析多解），存在任一分支在限位内且FK残差≤E7即为可达。这里只判存在性，不检查碰撞与分支连续性（留给路径评估逐检查点做）。
  4. s_k＝从s_cur起向前，第一段连续可达样本的末端；中途遇到第一个不可达样本即停止搜索。没有任何可达样本时s_k＝s_cur（Δs＝0），候选照常生成、可选（与原地候选Δs＝0的处理一致，[SRC-0392](../../../SOURCES.md#src-0392)⑦）。
  - 选“第一段连续可达”而不是“任意可达的最远点”的理由：路线回折时，后面的路线段可能重新落入可达范围，取最远点会让末端跳过中间不可达的路线段（推导，[SRC-0397](../../../SOURCES.md#src-0397)）。
- s_k单调：s_k ≥ s_cur，且不超过路线长度L。

### A.4 原地候选（规则5，**已定**，[SRC-0392](../../../SOURCES.md#src-0392)⑦）

- c＝(0, 0, 0)，底盘不动、不转向。
- 不同步：s_k＝在当前底盘位姿上按A.3算得的进度；时长＝(s_k−s_cur)÷s推进速率上限（B7/E8）。
- 同步：持续到末端走到同一计算得到的进度为止，时长＝(s_k−s_cur)÷v_ee（E8）。
- s_k不比s_cur远时Δs＝0、时长0：照常生成、可选；被选中时按task7.4⑧作为一次无推进的决策，计入卡住计数m。

### A.5 候选排列、掩码与K

- K_max＝13（**已定**U17上限）。
- 槽位（**建议**R5）：固定槽位——槽j（0…11）＝扇区j，槽12＝原地候选；被走廊粗筛放弃的扇区视为“未生成”，其槽位按补齐空位处理（掩码＝0）。
- 与“不屏蔽不可行候选”不冲突（**已定**，[SRC-0361](../../../SOURCES.md#src-0361)③）：走廊粗筛属于规则2的生成步骤；已生成但路径评估不可行的候选掩码仍为1、可被选。
- 对task7.10的要求（建议）：Actor/Critic对候选共享权重、不使用槽位编号嵌入，选择只依赖候选内容与掩码；这样固定槽位与紧凑排列在学习上等价，固定槽位只是便于诊断。
- 不保留历史候选（**已定**规则6）：每次决策只由当前输入生成。

### A.6 诊断量（只进日志与info，不进观测、奖励或f_k）

- 每次决策：生成的扇区候选数n_gen（0–12）及各扇区放弃原因；是否只剩原地候选；候选的Δs分布；s_k搜索的IK调用次数与耗时。
- 汇总：“无可行候选比例”（父TASK §5、task7.4 §17次要指标，已列）；“只剩原地候选比例”。
- 计算量估计（推导，[SRC-0397](../../../SOURCES.md#src-0397)，待task7.6实测）：走廊检查每扇区约32×14≈450格，可忽略；s_k搜索每候选的IK调用受可达球限制，直线路线约≤40次，13个候选约≤520次。路径评估举例为13×32×10≈4000次（父TASK §5），生成阶段约多一成。同步变体只有原地候选需要搜索。

### A.7 已知限制与风险

- 直线走廊粗筛会放弃“直线被挡、但曲线能到”的方向；障碍密集时可能只剩原地候选，造成卡住终止。须用A.6诊断量在阶段0/1度量；d越小，被挡概率越低。
- s_k取可达段末端，末端可能贴近工作空间边界（可操作度低、接近奇异位形）。路径评估记录可操作度与关节跳变（task7.5 B.4）；是否需要回退量，等实测后另定，本规格不加。
- 墙或障碍未被观测时，候选点可能落在其后；按I1由真值碰撞报失败，属设计内的感知限制。
- 规则候选与N²M²/CBL的末端路线规划都使用0.8 m量级的距离，但含义不同（A.3）；不能据此推断候选“通常可达”。

## (B) 生成网络改造方案（不实施；替换需另行授权）

### B.1 结构（借用SC²-WM后处理，不用其权重）

- 网络只替换规则1–2（底盘候选点放在哪里）；朝向（规则3）、s_k（规则4，精确IK）、原地候选（规则5）保持规则计算，K_max＝13与SAC接口不变。
- 输入：与VCM编码同一套3通道局部输入（G的2通道＋末端未来路线通道，task7.8 V3）＋变体标志；只用传感器、本体与任务路线。
- 输出与后处理：B_t中128×128热力图 → 12个30°扇区各取峰值 → 删去落在已观测障碍格（高度>0）上的峰值 → 合并邻近点 → 取前k → 距离窗口。该流程对应SC²-WM代码：减最小值、12扇区取峰值、按预测占据删点、16格分箱合并、top-8、0.1–5 m窗口（[SRC-0395](../../../SOURCES.md#src-0395)）；分箱尺寸、k与距离窗口不照搬，改造时另定。
- 不使用SC²-WM或CWP权重：输入需27类语义、场景为室内住宅、不知道末端路线，且权重不在本机（[SRC-0358](../../../SOURCES.md#src-0358)）。

### B.2 标签来源（R7，以后由用户选）

外部做法：VLN-3DFF用CWP修正后的连通图节点画σ＝5格高斯并取平均作热力图标签、MSE训练（[SRC-0389](../../../SOURCES.md#src-0389)）；CWP的标签来自MP3D连通图再经几何修正（[SRC-0390](../../../SOURCES.md#src-0390)）。两者都依赖已有的导航连通图，不是UR5整臂可达或连续IK标签。本项目没有连通图，需在理想SIM中自动生成：

|方案|标签怎么来|优点|问题|
|---|---|---|---|
|L1（建议）|在采样状态下，对一圈候选位置按本项目路径评估计算“最优路径可行，且（不同步）Δs>0”，碰撞只用当时的局部栅格；再平滑成热力图|与运行时信息一致，不含真值；网络只是把规则加路径评估摊销成一次前向，并能给出非固定距离/角度的点|不能比局部栅格知道更多；质量上限是路径评估|
|L2|同上，但碰撞用真值地图|候选更好|把“未见障碍”的知识注入生成器，与f_p“推测未见区域”的作用重叠，削弱G4对G2/G3的检验（所有组共用生成器，但世界模型的边际作用会变小）|
|L3|经验池中实际执行的结果（到达、Δs）|来自真实结果|只覆盖被选中的候选，带策略选择偏差（与f_p只在到达样本上有标签同类问题）|

三种方案推理时都只用传感器、本体与任务路线，满足“推理不用特权信息”。L2的问题在于研究设计层面，不在推理信息权限。高斯尺度等参数不照搬外部值（[SRC-0390](../../../SOURCES.md#src-0390)）。

1. 规则版已实现，并有阶段0/1的诊断基线（无可行候选比例、只剩原地候选比例、每次决策耗时）。

## (C) 子目标环暂缓（已定暂缓，[SRC-0359](../../../SOURCES.md#src-0359)）

- 出现以下任一情况时，向用户报告并由用户决定是否重新考虑（不自动启动）：

  3. G4对G2、G3的主要比较已有结果（避免在世界模型检验期间引入第二个自适应部件）。
- 若以后要做，须作为单独对照组另行授权，不并入现有G1–G6。
