|机械臂碰撞|机械臂连杆与立方体、墙或地面相交（N²M²解析sim中机械臂经MoveIt场景检查，场景只含机器人自身与地面平面，未见随机障碍加入，因此缺机械臂对随机障碍的检查，[SRC-0360](../../../SOURCES.md#src-0360)④已按[SRC-0367](../../../SOURCES.md#src-0367)收窄；本项目立方体有机械臂工作带高度层，必须检查）|
|自碰撞|机械臂与自身或车体相交|

ManiSkill中另记：真实接触（计为碰撞失败）；末端跟踪误差属于控制执行误差，与IK失败分开记录（根AGENTS §4）。关节跳变只作指标。

### 4. 段中途失败的处理（用户决定，U24）

训练、评估与ManiSkill统一：

1. 执行器在失败检查点之前停下，状态留在最后一个可行检查点（同步变体中末端时间同样停在该点），本次决策结束；
2. 记一次失败（类型、检查点序号、所选候选）；
3. 回合继续，从停下的位置做下一次决策；
4. 回合内失败累计达到F次（E2）→ 判为失败并终止。

失败的判定只按真值（2026-10-19用户决定B11，[SRC-0378](../../../SOURCES.md#src-0378)）：只有IK失败或真值碰撞触发上述停下与计数；局部栅格判为不可行只影响路径评分，不触发停下；不设安全层。这与CBL只记真实发生事件的口径一致（[SRC-0360](../../../SOURCES.md#src-0360)）。

时间与记录口径（2026-10-19晚按Codex复核补充，由第1条推出，不改上述规则）：本次决策记录的Δt＝从决策开始到最后可行检查点的仿真时长；同步变体中末端逻辑时间与底盘、关节一起停在该检查点，回合仿真时钟（用于T_max）也只累加Δt。若第一个检查点就失败，Δt＝0、折扣γ^0＝1，但失败计数已加1、r_t记录了失败，状态已经改变：这条决策照常写入经验池，不因“位姿未动”省略或合并。连续零时长失败由F（E2）与卡住判定M（E3）限制，不另设最小时长。

不屏蔽不可行候选（用户决定）：SAC可能选到最优路径不可行的候选，失败按上述规则发生，由失败惩罚与候选特征学习避开。规则选点对照组按其定义只在可行候选中选。ManiSkill中由执行器在线检查与接触检测触发同一规则。

### 5. 其它终止

- **卡住**：连续M次决策末端无推进（含无可行候选导致的停滞）→ 判为失败并终止（E3）。
- **超时**：决策次数达到D_max或仿真时间达到T_max → 截断；截断不是终止状态，Critic仍用下一状态价值自举（E4）。
- **到达终点**与各条件的处理顺序（2026-10-20用户决定⑧，[SRC-0392](../../../SOURCES.md#src-0392)）：到达路线终点即terminated，有历史失败时记“到达但非严格成功”、不给R_succ；同一检查点的判定顺序、终止优先于截断、T_max只在决策边界检查，见下文“2026-10-20 合同缺口决定”节。

### 6. 奖励（每次决策计算，半马尔可夫累计）

- 不同步（P）：`r = w_p·Δs − w_t·Δt − w_f·n_fail + R_succ·1[到达终点且成功]`
- 同步（T）：`r = w_p·Δs − w_f·n_fail + R_succ·1[到达终点且成功]`；无失败时Δt与Δs成正比，时间项可省；是否加N²M²式末端残差惩罚待定。（2026-10-20：下层可调末端速度后“成正比”不成立，是否加时间项待定，见文首修订节第4条。）

- 各组（父TASK §4）使用同一奖励。N²M²奖励为逐步稠密惩罚、无进度项（[SRC-0360](../../../SOURCES.md#src-0360)），结构不同，不直接沿用其数值。

**⑦ 到达、原地候选与决策超时**（2026-10-20：以下为G7旧合同；主方案见文首修订节第7条）

- 到达＝路径计划终点走完：底盘到达候选位姿，且不同步变体s＝s_k、同步变体计划时长走完。
- 同步变体的原地候选：底盘不动，持续到末端走到“从当前底盘位姿IK可达的最远进度”（与父TASK §2.8规则4同一计算）为止。该进度不比当前s远时Δs＝0，候选照常生成、可选。不同步变体的原地候选为“底盘不动、s推进到s_k”，时长＝(s_k−s)÷s推进速率上限（B7/E8）。
- 决策超时＝决策开始时所选最优路径的计划仿真时长×系数κ（κ待定），整次决策固定，不随重规划重算，不用墙钟时间。超时只结束本次决策，结果类型记“超时”，不计失败。

**⑧ 结束条件与处理顺序**（每个检查点按序判定）

1. IK失败或真值碰撞 → 不提交该检查点，停在上一个可行检查点，失败数＋1；累计达F → terminated（失败）。失败检查点不提交，所以“失败”和“到达终点”不会在同一检查点同时成立。
2. 否则提交；s到达路线终点且残差在E1以内 → terminated（到达）。整回合零失败才算严格成功并给R_succ；有历史失败记“到达但非严格成功”。
3. 否则到达c*或决策超时 → 本次决策结束。
4. 决策结束后更新卡住计数，达M → terminated（卡住）。
5. 最后检查D_max/T_max → truncated。终止优先于截断；T_max只在决策边界检查（单次决策长度已由决策超时限住）。

**⑨ 全部路径不可行的候选**

- p_k*按分层排序选：可行路径永远优先；不可行路径之间首个失败检查点越靠后越好，再比U25评分。
