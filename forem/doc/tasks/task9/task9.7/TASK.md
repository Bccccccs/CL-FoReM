## 唯一拟议实验：B1-L（只改 actor/critic LR 日程）

**待评审、未授权实施。** 在同一后续冻结代码下，重跑 B1 对照 C 与候选 L，各 seed 4718/4719、每 run 从头 3M。唯一科学自变量是 actor/critic LR 日程：C 沿 B1 的 `exp_updates`，L 改 `linear_transfers`（仍 1e-4→1e-6，按 3M 归一化）。保留 B1 的 capped 温度规则、α LR 固定 1e-6、update 间隔 10、其余科学合同。数值来自已有两种日程，不是声称文献最优。[草案依据与工程选择 SRC-1361](../../../SOURCES.md#src-1361)

理由：B1 稳定但 3M 末 LR 仍约 7.586e-5；B3 同时改变温度包和 LR，不能解释差异。B1-L 补充“低更新比＋原温度＋线性 LR”这一未测试组合，以区分改变 LR 日程是否有助于严格成功。假设可能被否定：快速衰减也可能妨碍学习。此实验不验证失败恢复机制，更不保证解决 20 次失败终态。[SRC-1359](../../../SOURCES.md#src-1359)、[SRC-1361](../../../SOURCES.md#src-1361)

**拟议预算**：4 新 run×3M＝12M 正式消费转移（含各首 250k profile）；smoke 总计不超过 4,000 消费转移；合计不超过 **12.004M**。单空闲 GPU 串行，正式每 run 至多 12h（含保存退出），G1≤1,800s、两组 smoke 各≤4,300s；拟议总上限 **52 worker h、52h 全局墙钟**。12h 是旧 B1 完整 10.161/10.265h 的规划代理，不是新组上界实测或工期保证；需另获预算批准及性能门通过。[SRC-1360](../../../SOURCES.md#src-1360)、[SRC-1361](../../../SOURCES.md#src-1361)

**拟议验收**：四 run 全部正常 3M、两组每 seed 均不退化；L 最终验证和末三验证的组均值均严格高于同期 C，才称“两种子探索中观察改善”。展示所有逐 seed 差、失败、分层与成本；只满足其中一个指标即未改善。历史 B1 的 67%/66.333%和 B3 的63.5%/57.333%供复核，不取代同期 C。不使用迁移或峰值选模，不作统计显著性结论，不据此替换 B3-5M。[SRC-1361](../../../SOURCES.md#src-1361)
