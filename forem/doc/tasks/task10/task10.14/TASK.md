# task10.14 · 训练前后三策略配对验证

状态 review（36回合执行与复算完成，交决策者审核）；本清单未观察到训练后改善，见[RESULTS](RESULTS.md)及[SRC-T10-028](../../../SOURCES.md#src-t10-028)。执行负责人 Codex，决策者 Codex。本轮用户已按协议派发执行，授权边界见[SRC-T10-026](../../../SOURCES.md#src-t10-026)。目标是评估在线试训200更新后的选点效果，比较训练后策略、同次运行的初始策略与均匀随机有效选点。以12个固定验证场景上的完整路线严格成功为主指标，诊断两种地图难度与失败原因。[依据](../../../SOURCES.md#src-t10-025)

交付为冻结清单、三个策略逐回合原件、配对结果、资源账本和可独立复算命令。模型更新数必须为0。完成性与观察到的收益分别判定，未观察到收益也要如实交付。验收详见[流程](PROCEDURE.md)，结果记入[RESULTS](RESULTS.md)。

推荐 GPT6.1sol/medium、Sonnet5.5/medium，用于加载接口、配对和统计核对；涉及隐藏状态与RNG疑难问题可用high。执行者可自主选平台可用模型和推理强度，也可选Terra/Luna，按难度记录理由；可自行或先建档后委派子Agent，父负责复核。所有人共用本轮资源上限。
