# task12.2 执行流程

递归规则：每节点恰有TASK/PROCEDURE/RESULTS；新增子节点继承编号、先建档并登记输入/独占范围/依赖/交付/验收再派发，父复用原件核查受影响路径。本轮独立，无子节点。模型/选模委派权限同TASK，实际未知。

1. 预先plan.json固定16 sparse＋16 standard、32张不同train地图、种子125000–125031、首次合法sync_v5复位边界s=0。排除原型地图sparse_train_00000，不因标签替换状态。先获得全部32采样结果，保存源快照及实际24格心/至多12有效规则清单，再写inputs-frozen.json，此前禁止教师制数。获取上限300秒/状态，原生合法性拒绝采样不视为按标签挑状态，失败/超时保留原ID/分母。
2. 载入r2已验收权重仅推理，按原纯分数/支持点/可见几何解码；预先保存预测/几何允许集/所选ID，不接收标签。两批12格心、一批有效规则各推演一次；到达且段内零失败为正。无效规则pose/label=null，异常/中断不标负。原地无已有同姿态依据时只补1次，已选择格心以相同状态/姿态/合同和ID复用结果，不重复推演。
3. 主四类按24格心：无正、全被几何排除、可选正例但排序漏选、至少命中一正；不完整标签/获取失败单列missing。规则正例覆盖/有效槽数独立，另报格心＋规则并集正例，不混分母。保存同扇区被选负分数减最高正分数及候选ID；局部标签不解释为完整路线成功率。
4. 分开计获取/候选生成/格心制数/规则推演/网络输入与推理/解码/额外原地推演/写盘，逐状态分布及PyTorch峰值显存、设备采样峰值和异常成本。每状态/批次原子保存；在途PredictionCore每25调用持久化，恢复保留done行，不重算完成候选。已完成状态跳过；STOP/TERM在安全actor边界保存，非静默负例。非预期错误停下保留证据，不盲目循环。
5. 持久host launcher用独立session＋文件锁防重复启动，记录driver/worker PID、日志、退出码。只用现场确认空闲的单GPU（计划物理2），GPU1留task10；原run/权重/代码只读，新namespace可写。初始8小时工程窗（非硬截止），完成32后自动停止并汇总可复算JSON/CSV与四份文档，状态review。启动核实后退出聊天主动监督。

实际运行版本、冻结清单、恢复/停止命令和原件在RESULTS及[SRC-T12-010](../../../SOURCES.md#src-t12-010)。32完成后的采样/训练/扩制数建议只作建议，不实施。
