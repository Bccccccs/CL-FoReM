### 2. 本项目实际结构（以task7设计为准）

- **下层SAC**：以10 Hz闭环运行，以子目标为条件，输出(vel_norm, ω, v)，无记忆，看局部栅格，机械臂由IK求解；单独训练后冻结（[task7 TASK §2.3](../../tasks/task7/TASK.md)，[SRC-0400](../../SOURCES.md#src-0400)、[SRC-0401](../../SOURCES.md#src-0401)）。
- **上层离散SAC**：在K个候选点中选一个，按半马尔可夫决策过程处理，执行中途不重选点。
- **两种“想象”**：f_k是冻结下层在运动学模型里的确定性推演，预测自身（精确计算）；f_p是学出来的模型，预测到达后的扫描，即对环境的预测，测试期可以继续适应。
- 世界模型**只影响选点**，不反馈到下层动作（反馈到动作留待以后，task7 TASK §6）。
- 当前执行线是task8（PCD地图迁移与下层SAC问题），task7后续执行处于paused。task8是否保持同一两层结构以其文档为准；本记录不对此作判断。

### 3. 修正后的对应关系（推导，待文献核验）

|本项目模块|用户提议|修正后的对应|理由（文献待核验）|
|---|---|---|---|
|IK、关节/底盘执行（训练环境中理想化；ManiSkill中由物理控制器承担）|—|脊髓/脑干|快速、不学习、把指令变成执行；训练环境按理想执行处理，这一层相当于被理想化掉|
|下层SAC|脊髓|运动皮层＋脑干的习得技能（以目标为条件的运动原语）|看栅格、避障、向子目标推进，属于习得技能，超出脊髓反射的范围（[SRC-1301](../../SOURCES.md#src-1301)）|
|上层离散SAC|小脑|基底节（在相互竞争的方案中做选择）|在K个候选上打Q值、用softmax选一个，与基底节“动作选择”的解释结构相近（[SRC-1303](../../SOURCES.md#src-1303)、[SRC-1304](../../SOURCES.md#src-1304)）|
|f_k 身体推演|大脑|小脑前向模型（运动指令副本 → 预测身体后果）|小脑内部模型理论讲的就是给定运动指令、预测身体会怎样（[SRC-1305](../../SOURCES.md#src-1305)）|
|f_p 到达后扫描预测|大脑想象|海马/皮层的情景想象|大鼠在岔路口停顿时预演路径（VTE、序列预演），与“在决策点对候选做想象”相近（[SRC-1306](../../SOURCES.md#src-1306)、[SRC-1307](../../SOURCES.md#src-1307)）|
|f_p 测试期适应|—|类似小脑的误差驱动适应|都依靠预测误差持续校准（[SRC-1305](../../SOURCES.md#src-1305)）|

主要修正：神经科学中小脑通常不负责“做决定”，主要负责预测和校准，因此对应我们的预测部分，而不是上层SAC。Doya的分工（小脑做监督学习、基底节做强化学习、皮层做无监督学习，[SRC-1302](../../SOURCES.md#src-1302)）可作参照：f_p偏小脑/皮层，两层SAC偏基底节，VCM等编码器偏皮层。

由此得到的核心观点：本系统有两类“想象”——**对自身的精确预测（f_k）**和**对环境的习得预测（f_p）**，与生物系统中“小脑管自身、海马/皮层管外界”的区分一致。

### 4. 设计历史与论文叙事要分开（事实＋建议）

- **事实**：项目记录中，两层都学习的结构来自2026-10-20对齐CBL——CBL/N²M²的SAC以10 Hz输出底盘连续动作，而10-19的框架下层不学习（[SRC-0400](../../SOURCES.md#src-0400)）。生物类比是2026-10-27才提出的（[SRC-1300](../../SOURCES.md#src-1300)）。
- **建议**：论文中写“这一分工与生物运动系统的组织方式一致（mirrors / is consistent with）”，用来说明设计的合理性；不直接写“受神经科学启发而设计”。项目文档保持如实：两层结构来自对齐CBL，生物类比是事后的解释框架。

### 5. 类比能支撑的设计选择与对应对照组（建议）

|设计选择|生物对应|工程理由|实验检验|
|---|---|---|---|
|分“选择”与“执行”两层，而不用一个扁平10 Hz SAC|基底节慢速离散选择＋运动系统快速连续执行|时间抽象缩短信用分配时间跨度；子目标可复用|**目前无对照**（见下方缺口）|
|下层是学出来的，不是规则执行器|运动技能靠习得，不是硬编码|能闭环避障，并协调底盘与机械臂|G7（规则路径执行器）对主方案阶段1（task7 TASK §4）|
|想象只在决策点，用来影响选点|大鼠在岔路口停顿并预演（VTE），不是每一步都想象|每0.1 s都想象代价过高；决策点上只需对K个候选做一次|G4对G2/G3（有没有f_p）|

附带一点：下层冻结后可以直接在运动学模型中推演（f_k），即“拿自己的技能当前向模型”，对应小脑。这是“分两层并冻结下层”带来的额外好处。

**缺口（需用户决定）**：如果论文要正面论证“为什么要两层”，评审很可能要求在同一环境中用单层10 Hz SAC完成整个任务的**扁平SAC对照**。task7现有G1–G7中没有这一组；task5.5的单层SAC运行在CBL环境中，任务、观测和地图都不同，不能直接比较。备选做法：论文不正面论证两层的必要性，只把两层当作既定框架，重点放在“自身预测 vs 环境预测”。增加该对照会扩大实验范围并占用训练预算，须用户明确授权并另立实验任务。

### 7. 局限与风险

- **训练方式**：生物各层共同发育、一起调整；本项目先训好下层再冻结，不做联合微调。
- **反馈通路**：小脑会实时修正正在进行的动作，本项目的世界模型只影响选点（与task7 §6“留待以后”一项对应；这里只是指出对应关系，不是建议现在实施）。
- **时间尺度**：脊髓反射约在数十毫秒量级（待补证据），下层为100 ms；毫秒级控制在训练环境中不存在。
- **审稿接受度**：机器人方向评审一般不把“仿生”当作贡献；类比本身也不是新意（[SRC-1301](../../SOURCES.md#src-1301)已有系统论述，待核验）。
- 目前没有支撑任何叙事的实验结果（下层未完成验收，上层正式训练未授权，ManiSkill暂缓）；先定叙事、后看数据，存在两者对不上的风险。
