## 每阶段合理性判定

| 阶段 | 判定 | 继续条件 | 失败时处理 |
|---|---|---|---|
| P0 | 必须先完成正确性与可复现入口 | 参数真实更新、新容器可用、评测可重跑 | 停止正式训练，定位失败，保留历史产物 |
| P1a | 合理的最小可行实验 | 一步动作条件预测优于两个对照 | 查动作/dt/特征目标与数据覆盖 |
| P1b | 有条件合理，复杂度明显增加 | 序列边界/KL 正确，时序收益与成本明确 | 保留 P1a，不阻塞最小闭环 |
| P2 | 核心研究重点 | 结构匹配对照、梯度链、有效前瞻证据 | 查信号和分布偏移，不直接堆 P3/P4 |
| P3 | 有条件合理 | P2 有效且受控感知扰动明确 | 保留关闭，分析空间/时间失配 |
| P4 | 风险最高的扩展 | 因果更新、重置、实时与收益同时检验 | 默认关闭，阈值修订单列新实验 |
| P5 | 后置合理 | 用户启动、语言任务定义和感知可用 | 维持 P1-P4 的方法迁移定位 |

## 自审发现并已在文档内修正

1. P2 的 actor 和 critic 不要求内部向量完全相同；最小无记忆版本保留原 critic，避免无依据的同时改造。
2. 残差最后一层零初始化时 g 保持 1，避免两者同时为零使修正器无法学习。
3. P1a 一步有效但五步不优时可进仅一步的 P2，明确不能宣称多步通过，避免不必要阻塞。
4. P4 不强制依赖 P3 的收益，但所有对照 P3 开关一致，避免计划依赖循环。
5. 冻结世界模型且无共享梯度的分支不是“辅助损失改进策略”，已在评测协议中纠正。
6. P4 同步更新无法保证执行中硬截止，文档限制为事前 profiling 与超时后禁用，异步另做设计。
7. P1 标准化特征不能直接交给旧 actor head；P2 明确逆标准化与零修正往返测试，保证初始行为兼容。

## 尚不能由文档证明的内容

- 新模型是否改善成功率，以及改进是否来自修正信号；必须跑匹配对照。
- 11 GB 显存是否足够具体 batch 与模型，及控制周期能否容纳梯度更新；需实测。
- 已有 checkpoint 的训练质量/来源、原失败分布，以及 GPU 故障根因；P0 提供新证据。
- P1b 具体概率状态是否优于简化模型、P3/P4 是否值得增加；允许负结果和保留较简单主线。
