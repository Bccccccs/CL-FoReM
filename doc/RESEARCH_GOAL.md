# Husky 世界模型闭环研究目标

> **参考（DOCS-028）**：研究问题背景；执行顺序与实验安排以 [ROADMAP](ROADMAP.md) 为准。

更新：2026-09-28，RESEARCH-028。本文落实用户新要求及随后澄清；范围是现有 Husky + UR5 + Robotiq85 / N²M²/SAC，**不考虑 TopAY 和 NMoMA**。原始要求保存在[原文档案](archive/20260928-user-research-brief.md)，当前状态以 [PROGRESS](PROGRESS.md) 为准。

## 目标与问题

以 IJCAI 2027（CCF-B，截稿约2027年1月中旬，待官方CFP确认）投稿为暂定目标（D37；原IROS 2027为CCF-C，已由D35取代），形成有明确机制、完整实验与可复现实现的机器人研究工作。会议目标不代表创新性已成立、保证录用或已确认投稿日程；当前不撰写论文正文。

核心问题：在相同任务、数据和计算预算下，学习到的世界模型能否利用当前状态预测未来，并结合随后真实执行反馈，持续改善 Husky 移动操作决策，优于原有 SAC、容量匹配的纯反应策略和仅在开始时使用预测的方案？

按 Research Question → Hypothesis → Method → Experiment → Implementation 推进。每次重大代码修改记录对应 RQ、可证伪假设、必要对照和预计影响的行为语义；预测误差下降本身不能证明机器人收益。

## 当前研究边界

- SAC 始终输出最终执行动作；世界模型提供预测、状态修正或受控适应信号。当前不建设独立候选轨迹排序器，也不让世界模型直接选择最终动作。
- 已有末端规划器、IK、执行器的真实关系见 [SYSTEM_PIPELINE](SYSTEM_PIPELINE.md)。不把通用“全局规划→K条轨迹→评分选优”的示例当作仓库现状。
- 当前输入为机器人状态和局部占据图；RGB、语言、task semantics 不属于近期主线。不能称完整 VLN 复现。
- 现有 SAC 已依据每步观测反馈决策；需要验证的是世界模型参与后的额外收益。单次预测不是 WM 闭环，每步前瞻也不自动等于在线模型学习或重规划。
- 新行为默认关闭；保留 checkpoint、旧动作/终止/IK语义的结果，不混合比较。不预设 SC²-WM 移植本身足够构成论文创新。
- analytical 研究与 Gazebo 物理验证分线；前者的成功不能替代后者的实时性、真实传感器或硬件证据。

## 研究问题与停止条件

| 问题 | 可证伪假设 | 必须取得的证据 | 失败时行动 |
|---|---|---|---|
| RQ1：预测是否含决策所需信息？ | 动作条件预测在固定特征空间优于复制和无动作对照 | P1逐回合误差、状态/地图分块、动作敏感性、1/5步；选型只用train/val | 诊断目标/覆盖/时间对齐；不靠扩模型掩盖负结果 |
| RQ2：前瞻是否改善实际控制？ | P2真实前瞻修正优于匹配结构且无前瞻的策略 | SR主比较、perfect-success、碰撞/IK、路径/延迟；多训练种子 | 若只有容量或重训收益，撤回前瞻机制claim |
| RQ3：持续反馈是否必要？ | 每步以真实观测更新预测的方案优于一次预测及纯反应对照 | 相同预算、扰动时间可控的反馈消融，干预前后恢复曲线 | 若无附加收益，不将单次预测包装为闭环创新 |
| RQ4：记忆/在线更新值得成本吗？ | 在指定模型失配条件下，因果正确的校准/适应改善收益—延迟权衡 | 固定P3开关、每回合重置、相同初始权重、p95/p99/超时率 | 默认关闭；不能用附加模块绕过P1/P2失败 |

RQ1 工程前提不等于 RQ2 充分条件；RQ2 成立也不自动证明跨场景、物理安全或实时。

## 当前事实与阶段安排

截至本轮只读核查，P0 analytical 在 node01 的固定 IK 预算协议下已通过；P1a 已实现和评测，扩量训练因内存架构问题停止；本轮进一步确认窗口漏加时间索引（D33），旧预测报告降级为受影响历史，必须修复重训重评，当前没有可信的P1a出口证据。P2–P5 尚无验收。具体数值与产物见 [实验框架](RESEARCH_EXPERIMENTS.md)，本轮没有重跑实验。

保留已有阶段门槛：P0 analytical → P1a → P2-MIN；P1b 支持时序版本；P3/P4 有条件进入；P5 仍需用户另行决定。用户原十二阶段的“轨迹选择、优化器调参”不机械加入：本项目对应的是 SAC 前瞻与状态修正；需要真实新接口的扩展另立研究问题，不默认实施。

近期执行顺序：

1. 固定系统图、当前结果、数据身份与历史负结果，消除过期状态说明。
2. 单独认领 P1a 窗口索引修复与有界内存改造：先对独立正确参考验证时间对齐，再核对采样/归一化/训练语义及实测峰值，恢复扩量研究。
3. 在训练/验证集上诊断动作信号、静态特征比例与多步误差；先完成划分审计，再登记新一次性测试。旧测试不因换种子标签而重新变成未见数据。
4. P1a 达标后接 P2-MIN，先接口兼容、梯度、因果时序与保存恢复，再做匹配训练对照和反馈消融。
5. 核心收益可重复后扩展鲁棒性、泛化、计算成本与必要的物理实验；按证据决定是否引入 P3/P4。

## 进入论文写作的条件

问题和相对现有工作的差异可解释；主机制与正式 claims 有匹配对照；原始基线和修复语义清楚；每次独立运行数据可追溯；核心消融、鲁棒性、泛化、效率及失败案例齐备；实验脚本与环境/数据/checkpoint标识可重跑；物理与硬件限制明确。由研究记录形成论文，不能先定有利结论再挑结果。
