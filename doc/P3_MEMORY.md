# P3 - VCM 记忆校准详细安排

> **模块参考（DOCS-028）**：后置扩展，不在当前主线；执行安排见 [ROADMAP](ROADMAP.md)。

> 执行 Agent：按 AGENTS.md 登记任务与证据；不得在 P2 无收益时把记忆收益冒充修正收益。

**目标**：在可控的感知延迟、缺帧及动态障碍下，验证近期观测能改善当前状态估计与任务表现。

**架构**：记忆只保存过去观测特征，加入相对位姿/时间信息后交叉注意力检索，以门控融合校准当前特征；输出进入与之匹配训练的世界模型。

**技术栈**：现有 PyTorch 注意力/MLP、P1b/P2-SEQ 序列接口、测试专用观测扰动 wrapper。

**依据**：[P2](P2_CORRECTION.md)、[评测](EVALUATION.md)、[决策](DECISIONS.md)。

## 进入条件和文件

P2 已有匹配结构的有效对照，序列采样、reset 和历史重建通过。Gazebo 动态障碍结果额外依赖 P0-GZ 对应场景验收；analytical 可先做观测扰动实验。

拟新增：`wm/memory.py`、`wm/calibration.py`、`wm/observation_perturbation.py`、`tests/test_wm_memory.py`、`tests/test_observation_perturbation.py`。接入 `wm/encoder.py` 和序列训练入口，保持原环境奖励、动作和终止不变。

`memory.read(query, pose, timestamp) -> context` 只读取过去条目；`memory.append(feature, pose, timestamp)` 在本步查询完成后执行；`reset()` 清空 episode 历史。保存固定编码器提取的原始特征，避免反复保存校准输出形成自我强化。

## 任务步骤

- [ ] 构造实验 wrapper，在策略可见的局部图上施加延迟或缺帧，真实环境和奖励照常推进。先分别测各扰动，再测组合，不能混淆物理动力学变化和观测损坏。
- [ ] analytical 初始延迟档为 0/1/3 个决策步；缺帧概率为 0/0.1/0.3，缺帧保持上一有效图且记录年龄。测试扰动 RNG 独立于布局/策略 RNG。
- [ ] Gazebo 使用实际消息时间戳记录毫秒延迟和图龄，不把 3 步在不同控制频率下当作同一强度。配置在测试前冻结。
- [ ] 初始记忆长度 N=8、特征投影维 128、单层注意力，作为首轮配置；记录峰值显存和每步耗时。N=0 为无记忆对照，N=4/16 仅在验证集选型。
- [ ] 时间衰减使用非负可学习系数；空间提示使用坐标变换后的相对位姿。若融合空间特征图，必须先对齐坐标；不能直接平均不同基座坐标的占据图。
- [ ] 门控输出与当前特征同形，初始偏向当前观测但不饱和；空记忆严格返回当前特征，未来时间戳/无效条目必须拒绝或显式屏蔽。
- [ ] 在序列训练中重建相同记忆，明确 burn-in 长度覆盖 N；首个窗口、回合重置和目标切换的处理与在线执行一致。
- [ ] 校准改变世界模型输入分布，需在训练集上训练校准器与对应预测模型版本；P2 对照给予相同额外数据、更新预算和冻结策略约定，不直接套用只见过原特征的预测器宣称公平对比。
- [ ] 分别验证记忆读写顺序、无未来帧、reset 后独立、动态障碍旧信息过期、在线/离线一致、N=0 数值退回原路径。
- [ ] 在 clean、延迟、缺帧、动态障碍四组报告 SR、碰撞、IK、图龄、门控权重和延迟；记录强扰动失效边界，不仅挑有效档。

## 对照与验收

至少比较固定 P2、P2+等容量无记忆校准器、P2+完整记忆；额外去掉时间衰减/空间提示用于解释机制。正式主对照使用相同训练预算和任务种子。

- 工程：空记忆、跨回合、过期信息、扰动复现和序列一致性测试通过。
- 研究：预先指定一种主要扰动条件取得配对收益，clean 条件也报告；clean 明显退化时不能只引用受扰动提升。
- Gazebo dynobstacle 验收必须实际存在运动障碍和策略可见传感器更新；仅播放可视化不能替代闭环任务。

## 合理性与风险

受控扰动让“记忆为什么有效”可检验；单纯动态障碍结果无法区分记忆、训练分布和网络容量。旧记忆可能保留已移动障碍，时间和空间处理是必要前提。若 P3 无稳定增益，保留关闭配置，P4 可基于固定 P2 独立研究。

## 交付与审查重点

交付扰动 manifest、记忆 reset/序列回归、各强度对比表、clean 性能与开销。重点审查未来信息泄漏、位姿坐标错配、动态障碍残影、校准后的输入分布变化以及额外训练预算混淆。
