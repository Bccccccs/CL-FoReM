# 执行路线图（唯一执行计划）

更新：2026-09-28，DOCS-028，Claude Opus 5.5 /ybc。**本文件是当前主线唯一的执行计划**：做什么、按什么顺序、每阶段的实验/对照/规模/判据/决策点，都以本文为准。其他文档是背景参考或历史，与本文冲突时以本文和 [DECISIONS](DECISIONS.md) 最新条目为准。执行状态看 [PROGRESS](PROGRESS.md)。

## 1. 一句话目标

在现有 Husky+UR5 / N²M² / SAC 系统中加入 SC²-WM 式闭环：**世界模型前瞻并修正 SAC 的输入特征，机器人执行后用实际结果在线微调世界模型**；最终动作始终由 SAC 输出。投稿目标 IJCAI 2027（CCF-B，约2027年1月中旬截稿，D37）。

## 2. 方法：每个控制步做什么

```text
1 观测 o_t（41维状态 + 120×120 局部地图）→ 固定编码器 → 特征 z_t
2 SAC 先给预览动作 a_preview（不执行）
3 世界模型预测 WM(z_t, a_preview) → 变化量 Δ                    [P1 模块]
4 修正特征 z' = z_t + ψ(z_t, Δ) → SAC 输出真正执行的动作 a_t        [P2 模块]
5 机器人执行 a_t，得到真实 o_(t+1)
6 残差 = 真实 z_(t+1) − WM(z_t, a_t)，对预测器做一步更新；回合结束恢复原权重   [简化 P4 模块]
```

要证明的核心：**第6步把"现实与平时不同"（执行失配）的信息带进决策**，使闭环在失配下优于同等信息与容量的对照。只有第1–4步时，修正量只是当前观测的函数，预期等价于加容量。

失配来源（D39）：analytical 中注入的**底盘速度增益**与**底盘命令延迟**（训练随机化 + 受控实验）；**Gazebo** 提供"analytical 训练 → Gazebo 执行"的自然失配（只评测，不训练）。

```text
Stage0 前置验证 ──G0──▶ F1 设计冻结 ──▶ Stage1 闭环筛查 ──G1──▶ Stage2 正式验证 ──G2──▶ Stage3 写作投稿
(10-01～10-03)        (用户确认)       (10-04～10-20，       (11月，约12-20      (12月下旬～1月中旬)
                                        最迟11-20去留)        冻结结果)
```

- 每个 G 是**通过/停止**检查点。未通过就停下与用户讨论，不带病进入下一阶段，不在看结果后放宽判据。

- 时间只计实验耗时（编码/写作由 Agent 完成）。

## 5. F1 设计冻结（Stage1 开工前，需用户确认）

来自 [LOGIC-028](agent_logs/20260928-logic-review.md) 的必答问题，写成 DECISIONS 后才能写 Stage1 代码：

1. **S4 训练协议（L4）**：训练时是否在线更新世界模型；replay 如何恢复适应上下文；target 动作用哪个参数版本；回合边界如何重置。推荐默认：训练中也在线更新并逐回合重置，replay 存每条转移当时的"近期残差摘要"作为 ψ 的附加输入，避免依赖参数版本。
2. **S2 历史预算（L5）**：历史条件 SAC 能看多少步。推荐：与 S4 相同的回合内历史长度（最近 K 步的状态、动作、dt，K≥最大延迟+1），并披露参数量与计算量。
3. **判据口径（L7）**：名义条件可接受退化界（推荐 SR 下降≤0.05）；主比较同时计训练种子与测试回合的变异；开发用失配档位与正式留出档位分开。
4. 由 R0-3 结果确定：训练随机化范围（中度掉点档）与留出测试档（重度/范围外档）。

## 6. Stage1 闭环筛查

回答：最小闭环在失配下是否优于同信息、同容量的对照？

| 对比组 | 内容 | 用来排除的解释 |
|---|---|---|
| S0 | 普通 SAC（同失配随机化训练） | 基线 |
| S1 | SAC + 同容量 adapter，无世界模型输入 | 收益只是参数变多 |
| S2 | 历史条件 SAC（按 F1 的历史预算） | 收益只是看了历史 |
| S3 | 只有 P2：世界模型固定、不更新 | 收益只来自前瞻修正 |
| **S4** | P2 + 简化 P4：前瞻修正 + 在线更新 | 主方法 |

- 规模：5组 × 3个SAC种子(11/22/33) × 100k 环境步 = **15次训练**，约12并发，约7h墙钟。
- 评测：每次训练 × 3条件（名义 / 开发失配 / 留出失配）× 100回合（种子10000–10099）= 4500回合，约45min。
- S4 诊断（不训练、只作机制证据）：测试时关闭更新、打乱残差、Δ置零；可选"已知失配参数的理想预测器"上界（LOGIC L6）。
- **G1**：留出失配下 S4−S2 与 S4−S3 的 SR 差，按训练种子与回合双层 bootstrap 的 95% CI 下界 >0；名义退化在 F1 界内。
- 迭代：每轮约1天。未通过则按诊断调整（更新频率、ψ 输入、残差摘要等），每次调整记 DECISIONS；**最迟 11-20 去留**，未过则改投 NeurIPS 2027（约5月）。
