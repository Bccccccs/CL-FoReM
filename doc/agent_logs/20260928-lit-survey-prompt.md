## 1. 背景（为什么要调研）

项目：在 Husky 移动底盘 + UR5 机械臂（N²M² 框架，SAC 输出底盘速度调制，末端沿规划参考路径、机械臂每步用 BioIK 求逆解）上，研究“世界模型前瞻 + 执行后在线更新”的闭环能否改善决策。控制周期 0.1 s，底盘最大前进速度 0.3 m/s、角速度 1.0 rad/s。

Stage0 前置验证的结果（node01 仿真实测）：

- 世界模型的一步/五步预测在未见测试集上显著优于“复制当前状态”和“不给动作”两个对照（3 个训练种子均成立）。
- 在 analytical 仿真中注入**底盘速度增益**（实际速度 = 命令 × 增益）和**底盘命令延迟**（整步延迟）：
  - 增益 0.6–1.4、延迟 0–2 步时，SAC 成功率最多只从 0.70 降到 0.61；
  - 增益 1.8 时降到 0.55（下降 0.25，显著）；
  - 失配主要表现为 IK 失败增多、“无碰撞无 IK 失败的完美成功”下降（0.53 → 0.30），而不是任务失败。
- 推断的原因：机械臂每步重解 IK 吸收了底盘误差，SAC 每 0.1 s 重新观测、自行纠正。
- 世界模型执行后做一步梯度在线更新，只挽回失配带来的预测误差的约 0.6–8.7%。
- 即使没有任何人为失配，也有约 30% 的回合因 `ik_limit`（机械臂够不到参考末端位姿）而失败。

我们需要外部证据来决定两件事：(1) 我们注入的失配强度是否符合真实机器人；(2) 研究主线应继续“失配 + 在线适应”，还是转向“用世界模型前瞻预判并规避 IK/可达性失败”。
