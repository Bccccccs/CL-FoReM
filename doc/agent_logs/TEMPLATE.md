# 任务记录模板

- 任务 ID：使用 PROGRESS.md 中对应 ID，独立子任务加后缀。
- 执行 Agent：填写可区分身份。
- 开始时间：填写日期、时间和时区。
- 状态：planned / active / blocked / review / done。
- 目标与工作范围：列出将读写的仓库、文件和允许操作。
- 已读文档：AGENTS、进度、决策、阶段安排。
- 依赖/当前版本：代码 HEAD、工作区改动、容器和镜像标识。

## 进度记录

每条使用时间戳，写明完成了什么、发现什么、下一步是什么。区分计划、实测与推断。

## 改动与验证

| 时间 | 文件/命令 | 预期 | 实际结果/退出码 | 证据路径 |
|---|---|---|---|---|

尚未执行的命令必须明确注明，不能填写为通过。大日志和权重不入 Git，填路径和哈希。

## 长任务

未启动时写“无”。启动后记录容器、当前 PID/会话、完整启动方式、日志、产物、进度读取方式、停止/恢复方法。PID 使用前重新核实。

## 审查与问题

列出严重性、证据、处理方式、未消除的风险。完成状态需要列出已满足的阶段验收条目。

## 交接

写明下一步最小动作、阻塞、禁止重复的操作、需保留的进程和产物。更新 PROGRESS.md 对应任务行。
