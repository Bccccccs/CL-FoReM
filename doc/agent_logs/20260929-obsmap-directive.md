## 1. 背景（为什么做这个）

- 现有基线的规划器（`eeplanner.py` 的 `PointToPointPlanner._calc_6Dplan`）**每 0.1 s 在整张真值平面图上从当前参考点到目标重跑 A\***；SAC 看的局部地图也从真值图裁剪（`map.py:305`，`world_type=="sim"`）。路线始终正确，所以此前所有干扰（执行失配、观测延迟、前瞻、在线适应）都不影响成功率（见 [stage0 日志](20260928-stage0.md)、[FOLLOWUP](20260928-followup-pipeline.md)、[SCREEN](20260929-screen-pipeline.md)）。
- [CEIL-028](20260929-ceil-pipeline.md)：SAC 训练到 25 万步仍停在 0.66–0.69（policy-100k 0.70），随机策略 0.08——SAC 重要但在该设定下到顶。按 D57 规则转入“换设定”：**规划器不再拥有全知地图**。
- 原代码已有部署用的非全局模式（`map.py:103` 的 `update_from_global_costmap`，Gazebo/实机用传感器滚动代价图），但在 analytical 下被强制关闭。

## 3. 实验设计要求

1. **新增开关 `observed-map-v1`（默认关闭，关闭时一切输出逐字段不变）**：规划器 A\* 使用的代价图改为“至今已观测到的地图”：
   - 每步以底盘为中心、视角 270°（朝向底盘前方）、感知半径 r 做射线投射，把视线可达区域的真值写入已观测地图；被障碍挡住的区域不写入。遮挡规则须写明（例如只有高于传感器安装高度的障碍才遮挡），并在日志说明依据。
   - 未观测区域按“空地”处理（乐观规划，与 ROS 导航未知区域常见处理一致），须写明。
   - 回合开始时已观测地图为空，只含初始位置的一次扫描。
   - 已观测地图变化时更新规划器权重（`update_weights`），注意性能（每步重算膨胀地图可能很慢，需缓存或增量）。
2. **只改规划器的地图**。SAC 的局部地图、碰撞检测、IK、奖励、终止保持真值不变，从而只隔离“规划器知道多少”这一个因素。（SAC 局部地图也遮挡的版本可作为之后的第二步，本次不做或只作探索性附加，需标注。）
3. **配置**：r ∈ {3, 5, 10} 米，外加名义（真值全图）；policy-100k，确定性，`--ik-mode fixed --ik-iterations 100`，种子 10000–10099，同种子配对。名义结果应与 R0-3c 名义（SR 0.70）一致，作为一致性核对。
4. **必须记录“路线改道”**：每回合改道次数（相邻两步完整规划路线差异超过阈值，例如最大偏离 > 0.3 m，阈值需预先写明）、改道后若干步内的 IK 失败/碰撞。用来确认偏差确实发生、并判断失败是否与改道相关。
5. **判据先登记**：运行前在 `doc/DECISIONS.md` 追加 **D59**（当前最大编号 D58；写前重读文件）：某一 r 下 SR 相对名义下降 ≥ 0.15 且配对 episode-bootstrap 95% CI 上界 < 0 为“伤害通过”；另报 perfect-success、IK 失败/碰撞回合比例、改道统计。登记后不得因结果修改。
6. **注意预期**：场地 11×11 m、障碍多为低矮小块，r=10 m 时几乎全可见，伤害可能很小；这正是分三档 r 的原因。结果如实报告，不为得到伤害而调整设计。
